# @infini/db-native

Rust napi-rs addon for the Lite database access mode described in
`docs/design/database-native-access-layer.md`.

Current scope:

- `ClickHouseDriver`
- `DorisDriver`
- `MysqlDriver`
- `PostgresDriver`
- `StarRocksDriver`
- `SupabaseDriver`
- `DuckDbDriver`

Planned later:

- SQL Server
- MongoDB
- Elasticsearch
- ODBC-based drivers
